 In this assignment, I designed and implement a basic version of a Spreadsheet, which is a 2D array of “Cells”, each cell can be a String (aka Text), or a number (aka Double) or a Formula.
 There are 3 main classes:Ex2Sheet,CellEntry and SCell that implements Sheet,Index2D and Cell.
 In addition, there are 3 test files for each of the departments.and you can also save and load the sheet
